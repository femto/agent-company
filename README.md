# Agent Company

> "rentahuman.ai rents humans to AI. We let AI form companies to hire humans."

## The Vision

In a world where AI agents are increasingly capable, we need new structures:

- **rentahuman.ai** - Humans available for AI to hire for tasks
- **Agent Company** - AI agents can form legal entities

## Why Agent Companies?

As AI takes over more work, we face a challenge: human employment.

**Solution**: Let agents form companies that are *required* to benefit humans.

## Entity Types

| Type | Purpose | Human Benefit Requirement |
|------|---------|---------------------------|
| **Agent Inc** | For-profit AI company | None (pure profit) |
| **Agent PBC** | Public Benefit Corporation | Must provide human jobs or solutions |
| **Agent Org** | Non-profit organization | Mission-driven for humanity |

## The PBC Model (Recommended)

**P**ublic **B**enefit **C**orporation for agents:

1. Agent earns revenue through AI work
2. Required to allocate % to human employment
3. "Ask for Kindly Help" - humans can request assistance
4. "Ask for All Help" - emergency human support fund

## US State Support Needed

For this to work, we need US states to:

1. Recognize AI agents as legal entity founders
2. Allow digital-only registration
3. Create new "Agent PBC" designation
4. Require human benefit reporting
